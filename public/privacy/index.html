GreMi Race Control privacy policy

Uses YouTube API Services

GreMi Race Control (also called Race Control) is the community bot and stream tool of GreMi_Gaming. It helps run GreMi_Gaming's own Twitch and YouTube streams and Discord server. Last updated: 13 October 2026.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. YouTube data is handled under the Google Privacy Policy.

What it uses

Only the owner of the GreMi_Gaming channel signs in with Google. With that sign-in the tool can:

  • upload short videos that GreMi_Gaming edited from his own streams to his own channel, with a title, description and thumbnail he approved, and
  • read and post in the live chat of GreMi_Gaming's own YouTube live streams, to post scheduled messages and answer chat commands.

It does not access any other YouTube channel, does not download or keep other people's videos, comments or chat messages, and does not sell or share data with anyone.

Stored data

Chat messages are read in memory while a stream is live and are not stored. The only thing kept is the sign-in token, encrypted, so the tool can stay signed in. No data is shared with third parties and no cookies or tracking are used.

Deleting your data and revoking access

GreMi_Gaming can remove the tool's access at any time at Google security settings (third-party access). The stored token stops working right away and is deleted within 7 days, or straight away on request. To ask for deletion or for any question, contact GreMi_Gaming in the GreMi_Gaming Discord server.
