Race Control privacy

Race Control is the community bot of GreMi_Gaming. It helps run GreMi_Gaming's own Twitch and YouTube streams and Discord server.

What it uses

When GreMi_Gaming signs in with Google, Race Control can read and post in the live chat of GreMi_Gaming's own YouTube live streams. It reads chat messages while a stream is live to post scheduled messages and answer chat commands. It does not store chat messages, does not access any other YouTube channel, and does not sell or share data with anyone.

Stored data

Only the sign-in token is kept, encrypted, so the bot can stay signed in. GreMi_Gaming can remove access at any time at myaccount.google.com/permissions.
